### 📁 🧠 **Как начать работу с хранилищем SecondBrain**

1. **Распакуйте архив** `SecondBrainS4.zip`, полученный от организатора.
2. **Откройте папку в Obsidian:**

   * Запустите Obsidian.
   * Выберите: **"Открыть папку как хранилище"**.
   * Укажите распакованную папку.
   * Obsidian спросит, **доверять ли авторам плагинов** — выберите **ДА**.

> [!tip]- ✅ 🔧 Что делать, если Git не установлен?
> 
> > 🛠 Git — это программа, которая позволяет синхронизировать ваши заметки через хранилище. 
> > - [Установка на Win](https://git-scm.com/downloads/win).
> > - Для macOS установка описана перед командами ниже.
> > Без неё команды из инструкции ниже работать не будут.

3. **Первый раз: укажите имя и email для Git**

> Это технический шаг, который нужно сделать всего один раз — иначе Git не предоставит доступ к репозиторию с хранилищем заметок.
> ==ВНИМАНИЕ!== Если вы пользователь Git, то пропускаете этот шаг.

**На macOS:**

* Откройте **Терминал** (через Spotlight или Launchpad).
* Вставьте и выполните по очереди:

```shell
git --version
```

- Если появится запрос “Do you want to install the Command Line Developer Tools?”, нажмите **Install** — это установит Git.
	- Если он у вас установлен, то вы увидите ==git version 2.42.0(или любую другую версию)==

```bash
git config --global user.name "SecondBrainMember"
```

```shell
git config --global user.email "secondbrain@example.com"
```

**На Windows:**

* Откройте **Командную строку (cmd)** → Нажмите Win+R → введите `cmd`
* Вставьте и выполните по очереди:

```bash
git config --global user.name "SecondBrainMember"
```

```shell
git config --global user.email "secondbrain@example.com"
```

✅ Это сохранится навсегда — повторять не нужно.

4. **Найдите кнопку `Git` в боковой панели справа** (иконка со стрелками).
5. **Синхронизация:**
   * Нажмите кнопку **Pull** (↧) — **третья слева**.
   * После этого появятся общие папки (если ещё не появились).

6. **Создайте свою рабочую папку** внутри хранилища (например, `Рустам rustamaga`), и добавьте туда пробную заметку, можно с прошлых занятий.
7. **Нажмите `Push`** (⇡) — кнопка справа от Pull, чтобы отправить изменения.
8. **Нажмите `Commit & Sync`** (↥) — **самая левая кнопка** на панели Git.
   * Это сохранит изменения и обновит хранилище.

***

### ⚠️ Важно:

* **Обязательно нажимайте Pull перед началом работы и Push после.**
	* В хранилище настроен автоматический Pull, при открытии и на каждые 5 минут
* Работайте **только со своими файлами**, не меняйте чужие заметки.
* Если произойдёт конфликт — попросите помощи у Рустама, ничего страшного.
